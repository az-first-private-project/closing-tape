## 2. 阈值与三态

- 默认滚动窗口 **750 个交易日**，最少 250 个交易日；当前 R 的百分位、20% / 80% 分位都只用截至当日的历史计算（无前视）。
- 历史不足 250 日时退回固定阈值 **0.18 / 0.30**，并在页面标注「固定分位」。
- 禁止使用旧配对阈值 `0.4 / 0.62`。

| 条件 | 区间 | 目标仓位（创业板50 / 红利低波50） |
|---|---|---|
| R < low | 低估区 | 100% / 0% |
| low ≤ R ≤ high | 均衡区 | 50% / 50% |
| R > high | 高估区 | 0% / 100% |

所有切换按 **5 批**执行，单批不超过总仓位 **20%**；未提供当前持仓时只给目标仓位与分批节奏。

## 3. 页面结构

1. **今日读数**：R、两端收盘、滚动分位、下/上阈值、区间、统计区间与固定参考值；数据不同步时提示各指数截至日，R 按共同最新日计算。
2. **比价走势**：R 折线 + 两条阈值虚线 + 中间均衡色带；展示走势解读与阈值标注。
3. **持仓建议**：两项目标百分比、三态规则高亮、5 批/20% 纪律、改变建议的触发条件。
4. **风险提示与口径**：相对强弱不是绝对估值；高 R 不代表立刻反转；红利端收益依赖分红再投；免责声明常驻。
