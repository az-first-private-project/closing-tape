# GFNA V7 T4 · 牛熊位置 × 估值（6 宽基四面板）

> 日期：2026-11-13
> 入口：`/index-compare` 页面第 05 区块
> 接口：`GET /api/v1/market/bull-bear`
> 数据任务：`broad_indices`（每日管线 + 补缺 + 回补脚本）

## 1. 硬约束（来自提示词文件）

- 只允许 **6 个宽基指数**：沪深300、中证红利、上证指数、中证500、创业板指、科创50。
  **不得出现上证50、中证1000。**
- PE 是当前 TTM 绝对值，**不是**各指数自身历史估值分位，不得写“处于历史低位”。
- ERP 样本仅 **2016-11-15 ~ 2026-11-12**，不得说成覆盖 21 年。
- 归一化曲线各指数起点不同，**绝对高度不可横向比较**；对数轴等距代表等倍数。
- 科创50、创业板指日线起点较短，回撤不能与 2005 年起算的指数做等长对比。
- 不输出买入/卖出/加仓/抄底/目标点位/收益承诺；收尾使用固定合规语。

## 2. 数据口径

| 数据 | 来源 | 说明 |
|---|---|---|
| 当前 PE / 盈利收益率 / 回撤 / YTD / 年化 / 波动 | 提示词文件硬数据（2026-11-13，腾讯自选股行情） | 后端常量 `BROAD_INDEX_SNAPSHOT`，页面逐位展示 |
| 当前 ERP / 分位 / 股息溢价 | 提示词文件硬数据 | ERP 3.5698%（78.9% 分位）、股息溢价 2.513%（56.8% 分位） |
| 长周期价格 / 回撤 / 动量 | 本地 `market_indices` | 沪深300/上证/中证500/创业板/科创50 走新浪；中证红利 000922 走中证指数历史 |
| 200 日均线 / 历史高点 / 5 年高点 | 提示词文件硬数据 | 0/6 站上 200 日线；平均距历史高点 -35.7%、近 5 年高点 -26.3% |

- 价格共同最新日：**2026-11-11**（中证红利源最新到 11-11；其余到 11-13）。
- 页面把“快照数据（11-13）”与“价格序列（11-11）”分开标注，不混用。
- 数据任务 `broad_indices` 每日拉取 6 个指数；`scripts/backfill_broad_indices.py` 回补 2005 以来历史。

## 3. 四面板

1. **长周期归一化走势**：6 条线，对数轴；支持近 3 年 / 近 10 年 / 全周期切换。切换后重新按区间起点归一化，展示“区间一换，结论就变”。
2. **回撤 × 盈利收益率四象限**：横轴距历史高点，纵轴 1/PE，气泡大小=近 1 年波动率；虚线为 6 指数均值参考线；悬停显示名称、PE、回撤、YTD、波动。
3. **动量热力矩阵**：1M / 3M / 6M / 12M 区间收益；红涨蓝跌；由本地价格指数计算。
4. **21 年回撤史（沪深300）+ ERP 温度计**：沪深300 月度回撤面积图、8 个关键牛熊节点；ERP 当前值与分位用横向温度计展示。

## 4. 交互与合规

- 时间滑块：3 年 / 10 年 / 全周期。
- 估值口径切换：PE(TTM) ↔ 股债溢价 ERP；切换后明确提示“ERP 是市场级指标，不参与 6 指数四象限，两者不是同一件事”。
- 9 个术语折叠卡：PE、盈利收益率、200 日均线、回撤、ERP、年化波动率、对数轴、归一化、历史分位。
- 数据/解读标签：数字卡片标「数据」，判断/类比标「解读」。
- 固定合规语：`本内容仅为历史数据与估值状态展示，不构成投资建议。市场有风险，决策需谨慎。`

## 5. 已知限制

- 提示词附带的原始 PNG/CSV（含完整 ERP 历史通道、各指数动量明细）未随文件提供；当前 ERP 只用文件给出的当前值与分位，未伪造 10 年通道。若后续提供原始 ERP 日频序列，可补画完整的 ERP 通道。
- 原图使用 ECharts；本项目已有 Recharts，为避免引入第二套图表库，四面板用 Recharts + CSS 实现同等信息结构。
- 6 宽基模块嵌在既有 `/index-compare` 页面第 05 区块；页面上方的创业板50/红利低波50 风格轮动模块保持不变。
