## 1. 校准目标

| 指标 | 目标 |
|---|---|
| 五态覆盖 | 5/5 均出现 |
| 平均持续 | 主状态 15–40 个交易日 |
| 年切换次数 | ≤ 16 次/年 |
| 单一状态占比 | ≤ 60% |
| 方向一致性 | 各状态的平均 20 日收益方向与标签一致 |

## 3. 最终参数

只调整了 5 个阈值，其余沿用提示词：

| 参数 | 初始 | 校准后 | 理由 |
|---|---:|---:|---|
| `trend_m` | 0.20 | 0.15 | 原值下趋势上攻仅 5.9%，略放宽短期动量门槛 |
| `trend_b` | 0.50 | 0.40 | 同上；广度是趋势确认的滞后项 |
| `trend_q` | 0.30 | 0.20 | 同上；量能门槛过高会滤掉温和放量 |
| `bottom_t_abs` | 0.33 | 0.45 | 筑底需要容忍受中期趋势略偏正/偏负 |
| `bottom_v` | 0.35 | 0.80 | 原值只覆盖最平静的 35% 分位，3 年只有 32 天满足 |
| `bottom_q1` | 0.25 | 0.45 | 地量门槛放宽到 45% 分位，避免只有在极端缩量时才识别筑底 |

另新增一条兜底避险规则（提示词未覆盖的「估值便宜但趋势崩」场景）：

```
T < -0.50 且 V_q > 0.60 且 M < -0.30  →  risk_off
```

原因：原规则 1 要求 `R < -0.5`，但 R 含 ERP（估值越便宜 R 越高），
2024-01 这类「估值低 + 趋势崩」的行情永远无法触发避险态。新增条件后，
2024-01-19 ~ 2024-02-07（14 个交易日）被正确识别为避险下跌。

## 6. 已知边界

1. **2022-09 之前数据稀疏**（2021 年仅 56 只/日、2022 年 ~1486 只/日），
   不参与校准；2022-09 起广度样本约 4200 只/日，2023-07 起约 5100 只/日。
2. **750 日完整窗口到 2024-09 才满足**；2023-09 ~ 2024-09 使用扩展窗口
   （250–750 日），`data_quality=partial`。
3. **融资买入额从 2023-10 才回补**，此前 Q6 缺失、温度计 `margin_buy` 子项缺失，
   由可用子项重新归一，不补 0。
4. **北向净流入、偏股基金新发**无数据源，R5/Q7 永久缺失，计入 `completeness`。
5. 阈值是「历史回看校准」而非「样本外验证」；市场结构变化后仍需复核，
   不得对外表述为胜率或准确率。
